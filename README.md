# El proyecto modular: un sitio web multipágina y responsive para un negocio o emprendimiento.

### Con al menos:

1. Una página de inicio o landing que presente el negocio.
2. Una página de servicios o catálogo.
3. Una página de contacto con formulario.

En este caso, vamos a simular un negocio de veterinaría.

### La primera parte del proyecto

Esta parte correspondiente al entregable del día 2, el cual busca tener la estructura ssemántica del proyecto de las 3 páginas, correctamente conectadas.

Además la página debe ser publicada en github pages.

### La segunda parte del proyecto

Esta parte corresponde al entregable del día 3, el cuál se centra en la estilización de las tres páginas, manteniendo un diseño armonioso, respetando las diferentes reglas de contraste para mejor lectura, el uso de variables globales para mantener la identidad del sitio, el uso de medidas relativas para mantener la compatibilidad entre diferentes resoluciones, etc.

### Tecnologías

Para la elaboración de este proyecto se usó unicamente:

- HTML
- CSS

no se hizo uso de ningún framework ni librería de estilos.

### Comparación uso de CSS propio vs bootstrap (evidencia semana 2 - día 2)

| Criterio | CSS propio | bootstrap |
| :--- | :---: | :---: |
| Líneas de código escritas | 7 para una card | 8-9 para una card |
| Tiempo invertido | moderado | corto |
| Facilidad para hacer cambios | intermedio | intermedio |
| Legibilidad del HTML | Buena, pero depende del coder | intermedia, pueden quedar etiquetas con muchas clases|
| Conclusión | requiere de un manejo y conocimiento sólido, el estilizado puede llegar a tomar bastante tiempo | agiliza mucho el tema de estilos, pero al momento de requerir una personalización mayor toca empezar a combinarlo con css |
